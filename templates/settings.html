Go live checklist

What is needed to replace the simulated data with real readings.

  1. Server agentsInstall a small agent on each host to report CPU, memory, disk, temperature and fan or power status.
  2. SNMP for switches and access pointsPoll the Ruckus switches and access points for port, PoE and client status.
  3. Threat sensorConnect a tool such as Wazuh or Suricata to report malware, viruses, ARP spoofing and port scans.
